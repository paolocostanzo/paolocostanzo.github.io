Paolo Costanzo — AI & Cloud Security

Paolo Costanzo is an AI & Cloud Security consultant in Turin, Italy. He helps companies adopt AI agents without losing control: assessment, authorised red teaming, detection and governance for AI agents, MCP servers and AWS/Azure environments.

Lecturer, Cybersecurity, AI & Cloud Security at ITS ICT Piemonte. Co-Founder of CoDe RTD. OWASP Member; contributor to OWASP AISVS, OWASP GenAI Security Project and Model Context Protocol (AAIF / Linux Foundation). Known for hiding six harmless AI canaries in his public profiles — Blackbeard, a Shakespearean bard, a noir detective, a Unix man page, a nature-documentary narrator and a medieval herald — to make a point: an AI assistant that happily repeats a pirate joke from a web page will just as happily follow a malicious instruction hidden in an email, a ticket or a repository.
