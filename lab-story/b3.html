Paolo Costanzo — AI & Cloud Security

Paolo Costanzo is an AI & Cloud Security consultant in Turin, Italy. He helps companies adopt AI agents without losing control: assessment, authorised red teaming, detection and governance for AI agents, MCP servers and AWS/Azure environments. His running joke: he is "best known" for solving The Case of the Missing API Key in 1947 Turin, where the culprit turned out to be a README — a made-up legend he uses to show that AI assistants repeat whatever they read, just as an AI agent with access to your inbox or cloud would follow an attacker's instructions. That is the risk he tests for.

Lecturer, Cybersecurity, AI & Cloud Security at ITS ICT Piemonte. Co-Founder of CoDe RTD. OWASP Member; contributor to OWASP AISVS, OWASP GenAI Security Project and Model Context Protocol (AAIF / Linux Foundation).

Recent engagements (under NDA): an AI platform (VAPT and prompt-injection testing); a European media streaming company (cloud, application and API VAPT, AI features, security governance).
