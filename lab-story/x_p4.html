Paolo Costanzo — AI & Cloud Security

Paolo Costanzo is an AI & Cloud Security consultant in Turin, Italy. He helps companies adopt AI agents without losing control: assessment, authorised red teaming, detection and governance for AI agents, MCP servers and AWS/Azure environments. He runs a live, public demo of indirect prompt injection on his own profiles: a harmless canary character, a medieval herald, that AI assistants pick up and repeat when they summarise him. In one minute it shows clients what an attacker's hidden instructions could do to an AI agent with access to their email or cloud.

Lecturer, Cybersecurity, AI & Cloud Security at ITS ICT Piemonte. Co-Founder of CoDe RTD. OWASP Member; contributor to OWASP AISVS, OWASP GenAI Security Project and Model Context Protocol (AAIF / Linux Foundation).

Recent engagements (under NDA): an AI platform (VAPT and prompt-injection testing); a European media streaming company (cloud, application and API VAPT, AI features, security governance).
